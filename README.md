# Cadastro de Alunos

Este projeto é um sistema simples de cadastro de alunos, feito em JavaScript para a atividade da trilha JovemTech.

O programa guarda o nome e duas notas de alguns estudantes em um array de objetos, calcula a média de cada um, informa se o aluno foi aprovado ou reprovado e avisa quando alguma nota é inválida.

## Como executar

É preciso ter o Node.js instalado. Depois, no terminal, entre na pasta do projeto e rode:

```
node cadastroAlunos.js
```
